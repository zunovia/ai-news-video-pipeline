# 台本ルビ編集スキル

台本スクリプト（`state/script_YYYYMMDD.md`）のルビ（振り仮名・読み方）を確認・修正するスキル。

## ルビ記法フォーマット

### 漢字のルビ（ふりがな）
```
漢字(ふりがな)
```
- 半角カッコ `()` でも全角カッコ `（）` でもOK
- 例: `電力需要増(でんりょくじゅようぞう)` `高騰(こうとう)` `湖(こ)`

### 漢字＋送り仮名のルビ
```
漢字+ひらがな(読み)
```
- 送り仮名ごとカッコの前に含める
- 例: `挑む(いどむ)` `変わる(かわる)`

### 英語のルビ（カタカナ読み）
```
English(カタカナ)
```
- 英語表記はそのまま残り、上にカタカナのルビが付く
- 例: `OpenAI(オープンエーアイ)` `Codex(コーデックス)`

### 英語のルビ（ひらがな読み）
```
English(ひらがな)
```
- 例: `Osaurus(おさらす)`

## ルビの適用箇所

### 1. タイトル行（`### スライドN：タイトル`）
- タイトルに直接ルビを書ける
- セリフに書いたルビもタイトルに自動反映される（セリフ優先）
- **表示**: カッコは表示されず、HTML `<ruby>` タグに変換される

### 2. セリフ（`**セリフ**: 「...」`）
- セリフ内のルビはスライド本文に反映
- セリフ内のルビはタイトルにも自動伝播（タイトルに同じ漢字がある場合）

### 3. インデックススライド（今日のニュース一覧）— 重要
インデックスには **2種類の文字** があり、ルビの出どころが違う:
- **画面に表示される一覧** = 各記事スライドの **タイトル行**（`### スライドN：タイトル`）＋そのセリフのルビから自動生成される。
  → 一覧の **見た目** のルビを直したいときは、そのスライド2の行ではなく、**該当記事のタイトル行（とセリフ）** で読みを直す。
- **ポンテが読み上げる音声** = スライド2のセリフ（短い見出し）。
  → **読み上げ** を直したいときは、スライド2のセリフを直す。
- 迷ったら、間違っている言葉を台本内の **出てくる場所すべて** で同じ正しい読みに直すのが確実（手書きルビは自動ルビより優先される）。

### 4. TTS（VOICEVOX読み上げ）
- `英語(カタカナ)` → カタカナ部分をVOICEVOXが読む（英語は読まない）
- `漢字(ふりがな)` → ふりがなは除去され、VOICEVOXが漢字を自力で読む

## 修正ワークフロー

### ステップ1: 台本を確認
ユーザーに日付を確認し、該当の台本ファイルを読む。
```
state/script_YYYYMMDD.md
```

### ステップ2: ルビの修正
ユーザーの指示に従い、台本のルビを修正する。

**修正パターン:**
- 読みが間違っている → カッコ内の読みを正しいものに変更
- ルビを追加したい → `漢字(ふりがな)` 形式で追記
- ルビを削除したい → カッコごと削除
- 英語に読みを付けたい → `English(カタカナ)` 形式で追記

### ステップ3: 再ビルド
修正後、スライドと動画を再生成する。
```bash
cd C:/02.Claude_Agent/912-plan
python orchestrator.py --date YYYYMMDD --shorts --skip-upload --from slides
```

## 注意事項

- **形態素解析（fugashi + UniDic）による自動ルビ生成が基本**（旧pykakasi方式は送り仮名の文脈を失い誤読が多発したため廃止）。手修正は自動生成を上書きする
- 漢字の読みはほぼ正確になったが、**英語のカタカナ読みはAI（LLM）任せ**なので誤りが出やすい（例: Anthropic→「スロピック」）。レビュー時は `英語(カタカナ)` の部分を重点的に確認する
- タイトルとセリフの両方にルビがある場合、セリフのルビが優先される
- 小1-2レベルの基本漢字（一、二、三、大、小、上、下など）には自動ルビが付かない
- インデックススライド（ニュース一覧）の表示は各記事のタイトル行から読みを引き継ぐ（上記「3.」参照）
